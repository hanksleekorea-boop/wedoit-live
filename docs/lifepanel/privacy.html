무엇을 저장하나요?

직접 고른 목적·역할·언어·시간대, 상태 확인, 선택한 행동, 오프라인 수집 메모와 사용자가 가져온 LifePanel 사본만 이 브라우저의 기기 안 저장소에 보관합니다.

계정, 광고, 분석 추적, 외부 전송, 서버 동기화는 사용하지 않습니다. 도움 요청도 사용자가 직접 다른 수단을 고르기 전에는 전송되지 않습니다.

내 자료를 내보내고 지우는 방법

  1. 첫 화면의 판번호 사본 내보내기를 눌러 JSON 사본을 먼저 저장합니다.
  2. 자료를 없애려면 사용하는 브라우저의 사이트 설정에서 이 사이트의 사이트 데이터를 삭제합니다.
  3. 삭제 뒤에는 사본 파일이 없으면 복구할 수 없습니다. 기존 WeDoIt 원본 키는 LifePanel이 삭제하지 않습니다.

안전·의료·금융 안내

LifePanel은 진단·치료, 매수·매도·대출 실행, 비밀 신고를 지시하지 않습니다. 지금 위험하다면 지역 응급 서비스나 신뢰하는 사람에게 직접 연락하세요.
