직접 고른 목적·역할·언어·시간대, 상태 확인, 선택한 행동, 오프라인 수집 메모와 사용자가 가져온 LifePanel 사본만 이 브라우저의 기기 안 저장소에 보관합니다.

광고·분석 추적·자료 판매는 사용하지 않습니다. 도움 요청도 사용자가 직접 다른 수단을 고르기 전에는 전송되지 않습니다.

선택 Google 연결과 최신 보호본

운영 설정이 완료된 판에서 사용자가 Google로 연결을 직접 누르면 공개 OAuth Client ID와 openid profile drive.appdata 최소 권한을 사용합니다. 비밀번호·client secret·refresh token·private key를 LifePanel 코드나 저장소에 두지 않습니다.

접근 토큰은 메모리에만 두고 만료·거부·새로고침 때 폐기합니다. 사용자가 최신 사본 직접 저장을 눌렀을 때만 Google Drive의 앱 전용 비공개 공간에 최신 보호본 1개를 씁니다. 일반 Drive 파일과 다른 앱은 이 자료를 볼 수 없습니다.

복원은 원격·로컬 항목 수와 저장 시각을 비교한 뒤 별도의 적용 버튼을 눌러야 실행됩니다. 클라우드 보호본 삭제는 로컬 자료를 지우지 않습니다. 현재 계정 버튼이 비활성이라면 운영 OAuth 설정이 없는 판이며 외부 전송은 0건입니다.

초대 전용 응원 모임

운영 모임 서버가 연결된 판에서는 Google 계정 식별자, 모임 구성원·역할, 일회용 초대의 해시·만료 시각, 사용자가 공유한 행동 제목·완료 여부·응원 요청, 차단·신고의 최소 기록만 처리합니다.

연락처·정밀 위치·건강 원문·금융 원문·개인 메모는 모임에 보내지 않습니다. 모임은 2~8명 초대 전용이며 공개 검색·공개 프로필·공개 순위가 없습니다. 현재 화면이 ‘기기 안 미리보기’라고 표시되면 실제 사람에게 전송되지 않습니다.

내 자료를 내보내고 지우는 방법

  1. 첫 화면의 판번호 사본 내보내기를 눌러 JSON 사본을 먼저 저장합니다.
  2. 첫 화면의 내 자료 보호 센터에서 확인란을 선택한 뒤 LifePanel 자료만 삭제를 누릅니다.
  3. 삭제 뒤에는 사본 파일이 없으면 복구할 수 없습니다. 기존 WeDoIt 원본 키는 LifePanel이 삭제하지 않습니다.

안전·의료·금융 안내

LifePanel은 진단·치료, 매수·매도·대출 실행, 비밀 신고를 지시하지 않습니다. 지금 위험하다면 지역 응급 서비스나 신뢰하는 사람에게 직접 연락하세요.

결제 자료와 권리

현재 공개판은 실제 결제를 받지 않습니다. Plus 출시 후보 화면도 카드·계좌 정보를 입력받지 않으며 결제 공급자 연결 전에는 구매 버튼이 비활성화됩니다.

출시 뒤에도 카드 번호·계좌 번호·보안 코드는 승인된 공급자가 처리합니다. LifePanel에는 검증된 익명 계정 참조·상품·권리 상태·유효 시각만 두고, 환불·취소·구매 복원은 검증된 공급자 응답으로만 반영합니다.
