행복 기록은 해피스캔 ‘내 공간’에서 별도의 JSON 백업·가져오기·삭제를 할 수 있습니다. 아래의 Google 로그인·클라우드·모임·이전 목표 백업 설명은 기존 활동 도구에만 해당하며 새 행복 응답에는 적용되지 않습니다. 브라우저 자료 삭제나 기기 분실에 대비해 별도 백업을 보관하세요.

법적 운영자·대상 국가·준거법·문의 채널 확정 전에는 최종 약관이 아니며 법률 자문이나 준수 인증이 아닙니다.

1. 현재 서비스

해피스캔은 계정 없이 쓸 수 있는 로컬 우선 PWA·PC 웹 후보입니다. 운영 설정이 완료된 경우에만 선택적 Google 로그인, 클라우드 보호본, 비공개 친구 모임을 제공하며 로그인과 전송은 강제가 아닙니다.

2. 기록과 공유

사용자가 입력과 공유 범위를 정합니다. 친구 순위는 각 구성원의 동의가 있어야 표시되며 목표 이름·메모·기분은 자동 공유하지 않습니다.

3. 백업·복원·삭제

JSON 백업과 클라우드 보호본은 서로 대체가 아닌 복구 수단입니다. 서버 보호본은 로컬 기록을 자동 덮어쓰지 않습니다. 삭제 전 범위와 백업을 확인합니다.

4. 제한

의료·정신건강·금융·법률 전문 서비스가 아닙니다. 운영자 정보, 보관·삭제 기간과 신고 처리 목표는 운영자가 확정해야 합니다.
