해피스캔의 새 행복 측정·기분·회고·실천 기록은 이 브라우저의 IndexedDB에 별도로 보관합니다. 현재 자동 서버 전송·기기 간 동기화·광고 타기팅은 하지 않습니다. HS-8은 검증되지 않은 자체 성찰 도구이며 의료 진단이 아닙니다.

행복 기록은 해피스캔 ‘내 공간’에서 별도의 JSON 백업·가져오기·삭제를 할 수 있습니다. 아래의 Google 로그인·클라우드·모임·이전 목표 백업 설명은 기존 활동 도구에만 해당하며 새 행복 응답에는 적용되지 않습니다. 브라우저 자료 삭제나 기기 분실에 대비해 별도 백업을 보관하세요.

만 18세 이상 성인용 개발 후보입니다. 실제 법적 운영자·문의 채널·대상 국가 확정 및 전문 검토 전까지 아래 문서는 최종 공개 운영 방침이 아닙니다.

개인정보 처리 사실표

현재 코드와 비활성 운영 설정을 구분한 후보 초안입니다. 법적 처리자·대상 국가·권리 요청 연락처가 확정되기 전에는 최종 방침이 아닙니다.

새 행복 응답의 서버 전송
현재 자동 전송하지 않습니다. 웹 호스팅의 접속 기록 처리 조건은 운영자가 별도로 확정해야 합니다.
기기 저장
목표, 기록, 회고, 선택적 메모·기분과 설정을 현재 브라우저에 보관합니다.
선택적 전송
개통 후 Google 로그인과 수동 클라우드 보호를 직접 선택한 뒤 매번 보호본 만들기를 누른 경우에만 계정 식별자·표시 이름·보호본·선택해 공유한 모임 활동을 HTTPS로 Supabase에 전송합니다.
친구 공개 범위
초대한 비공개 모임에 응원 글과 선택한 행동 횟수만 공유합니다. 목표 이름·메모·기분은 자동 공유하지 않고 순위는 기본 비공개입니다.
외부 처리자
개통 시 인증은 Google과 Supabase, 선택 자료 보관은 Supabase가 처리합니다. 실제 법인·저장 지역·보관 기간은 미확정입니다.
분석·광고
현재 SDK 0입니다.
삭제
기기 삭제와 원격 삭제는 범위를 따로 확인해야 하며 실제 원격 삭제 경로 검증 전에는 일반 출시하지 않습니다.

데이터 유실 방지

수동 클라우드 보호를 켜는 것은 동의만 저장하며 자료를 전송하지 않습니다. 사용자가 매번 지금 보호본 만들기를 누른 경우에만 한 번 전송합니다. 실패한 전송은 기기에 남지만 온라인 복귀·앱 재실행·기록 변경만으로 자동 재시도하지 않습니다. 서버 자료는 로컬 기록을 자동 복원·병합·덮어쓰기·삭제하지 않으며, 사용자가 보호본을 내려받아 기존 복원 비교에서 확인합니다.
