해피스캔 전환판 안내 · 2026-09-04

해피스캔의 새 행복 측정·기분·회고·실천 기록은 이 브라우저의 IndexedDB에 별도로 보관합니다. 현재 자동 서버 전송·기기 간 동기화·광고 타기팅은 하지 않습니다. HS-8은 검증되지 않은 자체 성찰 도구이며 의료 진단이 아닙니다.

행복 기록은 해피스캔 ‘내 공간’에서 별도의 JSON 백업·가져오기·삭제를 할 수 있습니다. 아래의 Google 로그인·클라우드·모임·이전 목표 백업 설명은 기존 활동 도구에만 해당하며 새 행복 응답에는 적용되지 않습니다. 브라우저 자료 삭제나 기기 분실에 대비해 별도 백업을 보관하세요.

만 18세 이상 성인용 개발 후보입니다. 실제 법적 운영자·문의 채널·대상 국가 확정 및 전문 검토 전까지 아래 문서는 최종 공개 운영 방침이 아닙니다.

도움과 문의

실제 문의 이메일·폼·지원 시간·응답 목표가 아직 운영자로부터 확정되지 않았습니다. 가짜 연락처를 표시하지 않으며, 실제 접수·답변 리허설을 통과하기 전에는 일반 상용 출시를 차단합니다.

지금 스스로 확인할 수 있는 것

  • 기록이 보이지 않으면 같은 브라우저 프로필·주소를 열었는지 확인합니다.
  • 업데이트 전에는 '나 → 백업'에서 JSON 파일을 생성합니다.
  • 오프라인에서 열리지 않으면 한 번 온라인으로 완전한 앱 셸을 받은 뒤 다시 시험합니다.
  • 복원 파일이 거부되면 10MiB 이하, `wedoit.local-backup` 형식 v1, schema v6인지 확인합니다.
  • 삭제 전 백업이 실패하면 저장 공간·다운로드 권한을 확인하고 다시 시도합니다.
