# WeDoIt v26.4.0 P0 신뢰·접근성 개발 후보

v26.3.0의 근거 있는 통찰·흐름 편집을 보존하면서, v26.4 상세 개발 실행계획 P0의 첫 묶음을 구현한 로컬 후보입니다. 아직 공개판이 아니며, 공개 v26.3.0은 변경하지 않았습니다.

## 이번 첫 P0 구현

- 신뢰 안내 안에서 한국어·영어를 선택해 핵심 저장·개인정보 문장을 읽기
- `이 기기에만 저장 중`, 마지막 저장 시각, 온라인·오프라인 상태를 바로 표시
- 공용망·VPN에서도 기록을 다른 곳으로 보내지 않으며 우회 기능을 제공하지 않는다고 명시
- 개인정보·저장 안내 대화창에서 계정·서버 동기화를 추가하지 않았음을 설명
- 기본·큰·아주 큰 글자와 높은 대비를 사용자가 직접 선택
- 화면 읽기 도구가 저장 상태를 읽을 수 있도록 상태 알림을 제공
- PC는 넓은 화면·키보드 작업, 휴대폰은 빠른 기록에 맞춘다는 차이를 안내
- 목적(몸과 건강·배움·소비)을 고르면 그에 맞는 첫 행동 예시를 표시하고, 한 번 눌러 오늘 기록 시작
- 방금 기록한 한 건 되돌리기와 오늘 목표 숨기기
- 내 기록 JSON 받기, 가져오기 전 목표·기록 수 확인, 취소하고 돌아가기

## 이번에 아직 끝나지 않은 P0

- 기존 전체 화면의 영어 문장 다듬기
- 가져온 내용을 현재 기록과 합치는 기능은 아직 제공하지 않음. 먼저 미리보기·취소만 제공

## 실제 경계

- 이 화면은 계정, 서버 동기화, 네트워크 우회, 새 권한 요청을 추가하지 않는다.
- 기록과 화면 선택은 이 기기의 브라우저 저장 공간에 남는다.
- 자동 검사와 브라우저 검사는 통과했으나, 실제 휴대폰·동의한 실제 사용자의 과업 검사는 아직 하지 않았다.

공개 v26.2.0의 하루 리듬과 데이터 구조를 유지하면서, 기록이 3일 이상 쌓였을 때만 실제 흐름을 알려주고 행동 시간대를 직접 바꾸도록 확장한 후보입니다.

## 이번 판에서 달라진 것

- 기록한 날이 3일 미만이면 결론을 내리지 않고 남은 날만 안내
- 3일 이상이면 최근 7일의 자주 돌본 영역과 잘 이어진 시간 표시
- 7일이 되면 실제 기록한 날 수를 더해 한 주 흐름 표시
- 각 설명에 사용한 기간·날짜 수·기록 수를 함께 표시
- 행동마다 아침·낮과 오후·저녁 시간대를 직접 변경
- 오늘만 숨기기를 하루 흐름 카드 안에서 바로 실행

## v26.2에서 이어받은 것

- 아침·지금·저녁으로 나눈 오늘의 흐름에서 최대 5개 행동만 제안
- 흐름 카드에서 바로 한 번 기록하고 즉시 화면에 반영
- 최근 14일 행동을 삶의 8개 영역별 관심 분포로 표시
- 첫 기록 뒤 3곳부터 열고, 기록한 날이 3일 쌓이면 8곳을 모두 표시
- 3일 이상 쉬고 돌아오면 30초 시작·목표 낮추기·오늘 쉬기 중 선택
- 평가 점수와 빈 날에 대한 부정적 판단을 사용하지 않음

## v26.1에서 이어받은 것

- 따뜻한 프리미엄 색·글자·간격 체계
- 오늘·목표·함께·통찰·나의 실제 화면 이동
- 첫 방문에서 `물 한 잔`, `깊은 숨 3번`, `안부 한 번`을 한 번 눌러 목표 생성과 첫 기록까지 완료
- 삶의 8영역을 점수가 아닌 `삶의 궤도`로 표시
- 개발·연결 상태 카드는 `나 > 고급 진단` 안으로 이동
- PC 왼쪽 메뉴와 폰 아래 메뉴가 같은 정보 순서를 사용
- PC의 휴대폰 이어보기 QR과 키보드 입력 유지

## 보존한 계약

- 데이터 구조 버전 6 유지
- 로그인 없이 기기에 저장
- 기존 목표·이벤트·회고·알림·함께 기능 승계
- 외부 출처 없는 첫 실행
- 첫 화면 용량은 공개 준비 때 다시 측정
- 되돌림 대상: v26.2.0

## 아직 실제로 연결되지 않은 것

건강 플랫폼, Android 전용 기능, 원격 안전 전송은 기존과 같이 자동 실행하지 않습니다. 관련 개발 정보는 화면에서 숨기지 않고 `나 > 고급 진단`에서 필요할 때만 확인할 수 있습니다.
